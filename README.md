# Structura — DSA Visualizer

An interactive, browser-based visualizer for learning data structures and algorithms.

## Included topics

### Data structures
- Array
- Linked List
- Stack
- Binary Search Tree
- Queue
- Hash Table
- Min Heap
- Deque

### Algorithms
- Linear Search
- Binary Search
- Bubble Sort
- Quicksort
- Selection Sort
- Insertion Sort
- Merge Sort
- Heap Sort
- Shell Sort
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's shortest-path algorithm

## Run locally

No build step or dependencies are required. Open `index.html` in a modern browser.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the Pages deployment to finish.

The expected site URL is: https://rijul-mahajan.github.io/Structura/

## Notes

- This is a static, client-side application.
- GitHub Pages can host it directly; no Node.js, package manager, or server is needed.
- The interface loads Inter and JetBrains Mono from Google Fonts. If those fonts cannot be reached, system fallback fonts are used.
